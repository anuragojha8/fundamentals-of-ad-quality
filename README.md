# Fundamentals of Ad Quality
An interactive technical book for product managers with a CS background.

## Current milestone
Recreated curriculum, visual design, reading shell, and a small expected-value lab. The previous training engine and full manuscripts have not been restored. Planned chapter pages are outlines, not complete lessons.

## Preview
Run `python3 -m http.server 8765 --bind 127.0.0.1` in this directory and open http://localhost:8765. No installation or build step is required. Browser assets are local.

## Structure
- curriculum.json: ordered curriculum and practical outcomes
- index.html, styles.css, app.js: accessible reading prototype
- docs/design.md: visual and interaction rules
- docs/reconstruction.md: scope, architecture, milestones, and backup policy

## Backup
Commit and push every substantial milestone, then verify remote and local HEAD agree. Remote pending user selection. Until a push is verified, this folder is only locally backed up by Git.
