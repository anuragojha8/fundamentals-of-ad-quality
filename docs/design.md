# Design foundation
Warm ivory paper, deep charcoal text, rust accent, sage experiment panels. Georgia headings and system sans-serif controls; no external font dependency. Use a readable 70-character prose column and a wider workspace for experiments. Chapter navigation carries five parts and explicit draft status.

Lesson sequence: motivating question → simple worked example → mechanism and notation → interactive experiment → code exercise → PM decision → recap and sources. Progressive depth should let readers understand a mechanism before reading the derivation. Math and claims must remain precise even when prose is playful.

Support keyboard navigation, visible focus, labeled inputs, reduced motion, mobile layouts, and printable text. Use restrained wit grounded in Anurag's writing samples. Avoid mechanically adding jokes or fictional first-person career anecdotes.

The initial lab is deterministic expected value, not an auction implementation or an empirical performance claim. The reading shell contains one short design sample; all chapter outlines remain marked planned.
